# cd: move between folders

**Module:** Linux

**Topic:** Filesystem and navigation

## What is cd?

`cd` means **change directory**. It changes the location used by your current shell.

It does not move the folder itself or change the location of a running application in another process.

## Simple example

```bash
cd /tmp
pwd
```

The first command changes the location. The second confirms it; on a typical system, it shows `/tmp`.

## Three useful forms

- `cd ..`: go to the parent directory, one level above the current directory.
- `cd ~`: go to your home directory.
- `cd -`: return to the previous working directory, if there is one.

Think of walking into a room, going back to the corridor, and returning home.

## What if a folder name contains spaces?

Put the path in quotes, for example `cd "My Projects"` if that folder exists under your current location. Without quotes, the shell treats the words as separate arguments.

## Real example: No such file or directory

You run `cd logs`, but it fails.

**What to check:** Use `pwd` and `ls`. Is `logs` really inside the current directory? Is it spelled `Logs` instead? Linux commonly treats those names differently.

A permission error is a different problem: the folder may exist but your account cannot enter it. Do not automatically switch to an administrator account.

## What to remember

**cd changes your shell's location. pwd confirms where you arrived.**
