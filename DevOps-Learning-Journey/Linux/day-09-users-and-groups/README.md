## Before starting

Inspection examples can be read or tried without changing accounts. Account and group creation examples are optional and belong in a disposable Linux VM with administrator access. They are not required on your everyday computer or a shared server. The same username on another laptop is not automatically the same account.

## The connection to real work

People and applications need identities. Groups organise shared access, and sudo policy limits administrative work. Account creation is not the same as granting every permission.
