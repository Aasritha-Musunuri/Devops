## Before starting

Use an Ubuntu/WSL terminal. Every file example creates its own sample inputs under `~/devops-practice/day07`, so you do not need to guess whether app.log already exists. Repeat runs may replace the named sample inputs. Use only these practice files for the remove and edit examples.

## The connection to real work

A deployment handles real files: configurations, artifacts, logs, and backups. Know whether each command reads, copies, moves, edits, or removes data before using it.
