## Before starting

Use a Linux terminal, such as Ubuntu in WSL. The commands below inspect files or change the current shell's location; they do not delete or change file contents.

Output depends on your machine. There is no need to create sample folders or install software to read these notes. If an optional tool is missing, use the alternative described in its topic.

The first three commands answer three simple questions:

```text
pwd -> Where am I?
ls  -> What is here?
cd  -> Where do I want to go?
```
