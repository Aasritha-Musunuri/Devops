# DevOps Learning Journey

Daily preparation notes and practical examples. Each day has its own folder with the topics covered.

## Days

- [Day 1: How computers talk](day-01-how-computers-talk/README.md) - bits and bytes, binary, hexadecimal, ASCII and Unicode, clients and servers, HTTP requests and responses.
- [Day 2: OS basics](day-02-os-basics/README.md) - kernel, processes and threads, RAM and disk, databases and storage, CPU scheduling, and the filesystem tree.
- [Day 3: How a program runs](day-03-how-a-program-runs/README.md) - source code, compilation, linking, machine code, runtime, memory, processes, exit codes, .NET execution, and environment variables.
