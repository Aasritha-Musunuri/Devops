# Daily DevOps learning journey

I'm learning DevOps through hands-on exercises, one day at a time and one topic at a time. This repository records the lessons, my practical results, and what I learn while troubleshooting.

Start with [Day 1: How computers talk](day-01/README.md). The first day covers bits and bytes, binary, hexadecimal, text encoding, clients and servers, and HTTP requests and responses.

My existing cloud preparation notes are in [Cloud](Cloud/).

For each topic:

1. Read its short explanation.
2. Predict the result before running the commands.
3. Run the practical yourself.
4. Answer the checkpoint questions in `day-01/notes.md`.
5. Review the results and explain the concept before moving on.

The curriculum follows a 95-day preparation plan. Lesson guides were prepared with AI assistance; completed practice and personal observations belong in the notes. No software installation or cloud account is needed for Day 1.
