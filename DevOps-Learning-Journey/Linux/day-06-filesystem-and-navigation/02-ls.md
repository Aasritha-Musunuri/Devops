# ls: what is here?

**Module:** Linux

**Topic:** Filesystem and navigation

## What is ls?

`ls` lists directory contents. With no path supplied, it lists the current directory.

Think of opening a cupboard to see what is inside. `pwd` tells you which cupboard you are standing at; `ls` shows its contents.

## Start with one command

```bash
ls
```

The names you see depend on your current folder. Hidden names are normally left out.

## What do -l, -h, and -a mean?

An option changes how a command works.

- `ls -l`: show more details, including permissions, owner, size, and modification time.
- `ls -lh`: show those details with readable size units such as K and M.
- `ls -a`: include names that start with a dot, which are normally hidden.

You do not need to memorize every column yet. Start by identifying the filename and size.

## List another location

```bash
ls /var/log
```

This lists `/var/log` without moving the shell there. Some contents may require additional permission to inspect.

## Real example: the configuration file looks missing

The application uses `.env`, but ordinary `ls` does not show it.

**What to check:** Use `ls -a`. A dot at the beginning hides the name from the default listing; it does not encrypt the file.

## Important detail

In a detailed listing, a directory's size column is not the total size of everything inside it. Calculating directory disk usage is a separate task.

## What to remember

**ls shows names. Options let you ask for more detail.**
